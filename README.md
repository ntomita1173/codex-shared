# codex-shared

複数プロジェクトで使う Codex の共通ルールと手順書を管理します。
アプリのコードは各プロジェクトのリポジトリで管理してください。

## 使い方

このリポジトリをクラウド環境に追加し、タスクの冒頭で次のように依頼してください。
実際の配置先に応じてパスを変更してください。

> /workspace/codex-shared/AGENTS.md を読み、今回の作業に適用してください。

別のリポジトリにある AGENTS.md は自動適用されるとは限りません。
共有ルールとプロジェクト固有の指示が衝突するときは、ユーザーの指示と対象プロジェクトの指示を優先してください。

## ファイル

- AGENTS.md: 共通の作業ルール
- TASK_TEMPLATE.md: 作業依頼のテンプレート

秘密情報、API キー、個人情報はコミットせず、環境の安全な設定で管理してください。
